# wordle-app

This is a Wordle clone application, subject to further expansions and modification.

## Get started

Follow these steps to get the project running on your machine

### Prerequisites
Make sure you have the following installed:
* [Node.js](https://nodejs.org) (v18 or higher)
* [Git](https://git-scm.com)

### Installation

1. **Clone the repository**
    ```bash
    git clone https://github.com/daps-codes/wordle-app.git
    ```
2. **Navigate to the project directory**
    ```bash
    cd wordle-app
    ```
### Running the app
    ```bash
    node app.js
    ```
